# Robotic Arm Kinematics
Kinematics components for a robotic arm controller.

This project currently focuses on modeling robotic-arm geometry and building the foundations for forward and inverse kinematics in a simulated controller.

## Current Scope
* Linear Algebra required for DH parameters
* Denavit–Hartenberg (DH) parameter representation

## Status
Early development. Currently limited to foundational components.

## Roadmap
Future work:
* Add unit tests for components
* Implement forward / inverse kinematics
* Translate desired end-effector motion into joint movement
* Produce demo visualization of the arm moving between points in space
